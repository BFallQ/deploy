todo позволяет добавлять и убирать задачи в список. Все задачи хранятся в отдельной SQL таблице.
В разработке возможность авторизации. Список задач будет зависеть от авторизованного пользователя. 
Использованы:
Фреймворк Express и middleware express-session;
Интеграция SQL better-sqlite3;
Хеширование bcrypt;
Ссылка на рабочий frontend: https://bfallq.github.io/deploy-frontend/

  Что протестировано и реализовано:
  1. Регистрация и вход (bcrypt, express-session)
  2. Защита создания задач — доступно только авторизованным пользователям (401 без входа)
  3. Проверка на устойчивость к SQL-инъекции в поиске
  4. Валидация пустого тела запроса при создании задачи

  Что пока не реализованно:
  1. Регистрация с уже существующим username — корректно отклоняется (функция авторизации в разработке)
  2. Попытка добавить задачу без авторизации — 401 (функция авторизации в разработке)
