Todo позволяет добавлять и удалять задачи. Все задачи хранятся в отдельной SQL-таблице.

Использованы:
- Фреймворк Express и middleware express-session
- Интеграция SQL better-sqlite3
- Хеширование bcrypt

Ссылка на рабочий frontend: https://bfallq.github.io/deploy-frontend/

## Реализовано и протестировано
1. Регистрация и вход (bcrypt, express-session)
2. Регистрация с уже существующим username — корректно отклоняется
3. Защита создания задач — доступно только авторизованным пользователям (401 без входа)
4. Проверка на устойчивость к SQL-инъекции в поиске
5. Валидация пустого тела запроса при создании задачи

## Известные ограничения
1. Список задач общий для всех авторизованных пользователей — персональные списки (свой список у каждого) пока не реализованы
